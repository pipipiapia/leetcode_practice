## 每章结构

每章文件包含以下内容：

1. **原文**：以王弼本（通行本）为底本
2. **逐字注释**：对生僻字、古字、关键概念逐一解释
3. **白话译文**：尽量直译，保留原文韵味
4. **帛书版异文**：马王堆帛书甲乙本与通行本的重要差异
5. **历代注解**：
   - 河上公章句（汉）：修身养生视角
   - 王弼注（魏）：玄学义理视角
   - 林希逸口义（宋）：平易通达视角
   - 现代学者（陈鼓应、任继愈等）：学术研究视角

## 版本说明

| 版本 | 年代 | 特点 |
|------|------|------|
| 王弼本（通行本） | 魏（226-249） | 文人学士通用，义理畅达，流传最广 |
| 河上公本 | 汉（?） | 道教修身传统，每章有章题 |
| 马王堆帛书本 | 西汉（前168年入土） | 1973年出土，德经在前道经在后，多"也"字，"恒"代"常" |
| 郭店楚简本 | 战国（前300年左右） | 1993年出土，最早但仅存约1/3内容 |
| 北大汉简本 | 西汉中期 | 2009年入藏，保存较好 |

## 推荐阅读

- 王弼注，楼宇烈校释《老子道德经注校释》（中华书局）—— 玄学义理经典
- 陈鼓应《老子今注今译》（中华书局）—— 现代学术标杆
- 任继愈《老子绎读》（国家图书馆出版社）—— 哲学视角精炼
- 高亨《老子注译》（清华大学出版社）—— 文字训诂严谨

## 阅读建议

1. **初读**：先通读原文，不求甚解，感受节奏与意象
2. **精读**：逐章对照注释，理解每个关键字的确切含义
3. **比较**：对照帛书版异文，体会文本流变
4. **参证**：对比不同注家的解释，形成自己的理解
5. **体悟**：道德经非知识之书，重在生活实践中的体会
