# 帛书版与通行本主要差异

## 一、篇章结构差异

| 项目 | 通行本（王弼本） | 帛书本 |
|------|------------------|--------|
| 篇序 | 道经在前，德经在后 | 德经在前，道经在后 |
| 分章 | 81章 | 不分章（或分章不同） |
| 章题 | 无 | 无 |
| 总字数 | 约5000字 | 约5467字（乙本统计） |

## 二、避讳改字

通行本因避汉文帝刘恒讳，将帛书中的"恒"改为"常"：

| 帛书本 | 通行本 | 出处 |
|--------|--------|------|
| 道可道也，非**恒**道也 | 道可道，非**常**道 | 第1章 |
| 名可名也，非**恒**名也 | 名可名，非**常**名 | 第1章 |
| **恒**无欲也 | **常**无欲 | 第1章 |
| **恒**有欲也 | **常**有欲 | 第1章 |
| **恒**善救人 | **常**善救人 | 第27章 |
| 道**恒**无名 | 道**常**无名 | 第32、37章 |

帛书乙本避汉高祖刘邦讳，将"邦"改为"国"；甲本不避。

## 三、虚词差异

帛书本多出大量虚词"也"字，通行本大多省略：

| 帛书本 | 通行本 |
|--------|--------|
| 道可道**也**，非恒道**也** | 道可道，非常道 |
| 名可名**也**，非恒名**也** | 名可名，非常名 |
| 无名万物之始**也** | 无名天地之始 |
| 有名万物之母**也** | 有名万物之母 |
| 恒无欲**也**，以观其眇 | 常无欲，以观其妙 |
| 恒有欲**也**，以观其徼 | 常有欲，以观其徼 |

## 四、重要文字差异

以下列出帛书版与通行本之间对理解有重大影响的文字差异：

### 第1章
- 帛书："非**恒**道也""非**恒**名也" — 通行本："非常道""非常名"
- 帛书："无名万物之**始**也" — 通行本："无名**天地**之始"
- 帛书："两者同出，异名**同谓**" — 通行本："同出而异名，**同谓之玄**"

### 第2章
- 帛书："高下之相**盈**也" — 通行本："高下相**倾**"（避汉惠帝刘盈讳）
- 帛书："音声之相**和**也" — 通行本："音声相和"（帛书多出此句）

### 第5章
- 帛书："多闻**数**穷" — 通行本："多言数穷"

### 第8章
- 帛书："水善利万物而**有静**" — 通行本："水善利万物而**不争**"
- 帛书："居善地，心善渊，予善**天**" — 通行本："与善**仁**"

### 第14章
- 帛书："执古之道" — 通行本："执古之道"（同）但北大汉简本作"执今之道"

### 第25章
- 帛书："道法**自然**" — 通行本同，但帛书上下文"人法地，地法天，天法道，道法自然"中"人"作"王"

### 第31章
- 帛书："铦袭为上" — 通行本："恬淡为上"（意义完全不同）

### 第38章
- 帛书："上德无为而**无以为也**" — 通行本同
- 帛书："**下德**为之而**有以为**" — 通行本有此句，但部分古本无

### 第40章
- 帛书："有生于无" — 通行本同
- 帛书："弱也者，道之用也" — 通行本："弱者道之用"

### 第41章
- 帛书："大器**免**成" — 通行本："大器**晚**成"（"免"与"晚"意义不同）
- 帛书："天象无形" — 通行本："大象无形"

### 第45章
- 帛书："大直如**诎**" — 通行本："大直若**屈**"
- 帛书："大赢如**溶**" — 通行本："大赢若**绌**"

### 第52章
- 帛书："见**常**曰明" — 通行本："见**小**曰明"

### 第57章
- 帛书："法**物**滋彰" — 通行本："法**令**滋彰"

### 第61章
- 帛书："大邦者，下流也" — 通行本："大国者下流"（帛书用"邦"，通行本用"国"）

### 第63章
- 帛书："大小**多少**，报怨以德" — 通行本同，但"大小多少"理解有争议

### 第69章
- 帛书："吾不敢为主而为**客**" — 通行本同
- 帛书："祸莫大于**无敌**" — 通行本："祸莫大于轻敌"（"无敌"与"轻敌"意义不同）

### 第76章
- 帛书："恒强大居下" — 通行本："强大处下"
- 帛书："木强则**梗**" — 通行本："木强则**折**"或"兵强则**兵**"

### 第80章
- 帛书："受邦之垢" — 通行本："受国之垢"（邦/国之别）

## 五、帛书版的学术价值

1. **"恒"与"常"**：帛书作"恒"，通行本避讳改"常"。"恒"有持久、恒常之意，"常"有寻常、恒常之意，侧重点不同。
2. **"有静"与"不争"**：第8章帛书"有静"更强调水的沉静特性，通行本"不争"则突出道德意味。
3. **"免成"与"晚成"**：第41章帛书"大器免成"意为大器无需成就（自然而成），通行本"大器晚成"意为大器需时方成，意义迥异。
4. **"无敌"与"轻敌"**：第69章帛书"祸莫大于无敌"意为最大的祸患是没有对手（因而放松警惕），通行本"轻敌"则直接指向态度问题。
5. **虚词"也"字**：帛书多出的"也"字改变了断句和语气，影响对文义的理解。
